Voglio una semplice app desktop editor di file md. Deve essere leggerissima, avere una UI spartana, deve permettere di aprire file md, visualizzarli ed editarli. Può servire sia per crearli che per leggerli. 
Voglio usarla come app predefinita quando apro un file md con il doppio click sull'icona, voglio anche poter fare tasto destro -> nuovo -> file md e si apre l'app. 
L'UI e l'aspetto generale dovranno essere riconoscibili per l'estetica Diaspro, per farlo attingeremo alla cartella di risorse diaspro-general-features.
Creeremo una icona uguale a quella di diaspro ma con una m minuscola al posto della d.
